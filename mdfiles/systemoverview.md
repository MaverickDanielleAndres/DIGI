# Collective Memory Platform - System Overview

## Overview

This platform is a collaborative disposable camera and shared memory experience application designed for events such as weddings, birthdays, debuts, graduations, reunions, concerts, corporate events, and private gatherings.

Guests join events through a QR code and participate in a shared disposable camera experience where photos are automatically uploaded into a live collaborative album. The platform focuses on emotional storytelling, memory preservation, social interaction, and event personalization.

The system combines:
- Disposable camera mechanics
- Shared live albums
- Collaborative storytelling
- Event customization
- Social memory features
- AI-powered enhancements
- Gamification systems
- Real-time event engagement

---

# Core Vision

The system is not just a photo-sharing app.

It is designed to become:
> A collaborative memory preservation platform where everyone contributes their perspective to an event.

The experience centers around:
- Intentional photography
- Scarcity through limited shots
- Delayed gratification through reveal systems
- Emotional storytelling through notes and memories
- Beautiful event personalization
- Shared social experiences

# Core Experience Flow

## Event Creation Flow

1. Event owner creates event
2. Configures event settings
3. Customizes branding/theme
4. Generates QR/invite
5. Shares with participants

---

## Guest Participation Flow

1. Guest scans QR code
2. Enters event experience
3. Uses disposable camera
4. Captures photos/videos
5. Photos upload automatically
6. Memories appear in shared album

Optional:
- add notes
- add voice messages
- save as draft before posting

---

## Album Experience Flow

1. Photos appear in live album
2. Guests browse memories
3. Reactions/interactions occur
4. AI groups moments
5. Event owner curates memories
6. Event recap generated
